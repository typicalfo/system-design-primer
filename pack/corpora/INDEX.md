# Complementary sources

Works the System Design Primer does not cover, for use with the skills in this pack. This index links to them. It does not include their text. Nothing new was copied in this round.

Three classes:

- **Bundle-able with attribution.** The license allows a copy in a skill or a doc if the required notice travels with it (attribution, and for Apache-2.0 the license text). This pack still only links.
- **Share-alike.** The text is CC BY-SA 4.0. Copying it into this repo would require releasing the derived text under CC BY-SA 4.0 as well. This repo does not do that, so these sources are link only here for now.
- **Link only.** No open license was verified, the license blocks derivatives or commercial use, or the grant only allows unmodified copies and short attributed excerpts. Do not copy the prose in.

Licenses were checked against the page or the repository file named in the row. "May be bundled" in the first table means the license allows redistribution under the conditions stated. This pack still only links.

### Community Specification License 1.0

SLSA and OpenSSF S2C2F use Community Specification License 1.0 for their specifications. The license text is at https://github.com/CommunitySpecification/Community_Specification/blob/main/01-community-specification-license-v1.md . That text's own closing line says it is Copyright 2020 Joint Development Foundation and licensed CC BY 4.0. `https://github.com/CommunitySpecification/1.0` redirects to the Community_Specification repository. SLSA's copy is https://github.com/slsa-framework/slsa/blob/main/LICENSE.md and the spec is https://slsa.dev/spec/v1.1/ . S2C2F's copy is https://github.com/ossf/s2c2f/blob/main/LICENSE.md and the project is https://github.com/ossf/s2c2f .

In short, from that license, not as a substitute for reading it: it covers specification materials, not source code. A contributor grants a copyright license to reproduce and adapt what they submit. That copyright license is not sublicensable. A derivative of the materials has to name the working group, the version, and where the materials were retrieved. An implementation of the specification does not need that attribution. Patent licenses for claims necessary to implement the spec are royalty-free, contributors can exclude claims in a stated window, and the patent grant ends defensively if a licensee sues over such a claim. The patent terms apply to someone who has accepted the license, for example by shipping the license with an implementation or by recording acceptance in the repository notices. Source code in the working group's repository follows the source license named there, or the MIT license if none is named. S2C2F's LICENSE.md says the same split. Copies of the technical materials have to keep an as-is disclaimer of the kind the license describes. No other rights are granted. This pack links only.
